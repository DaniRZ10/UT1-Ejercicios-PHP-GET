# UT1-Ejercicios-PHP-GET
Batería de 6 ejercicios de PHP

## Ejercicios

- **parte1.php** — Lanza un dado con `rand(1, 6)` y muestra la imagen de la cara que sale.
- **parte2.php** — Igual que la parte 1, pero guarda el histórico de tiradas en la URL (`?resultados=4521`) y lo muestra en una tabla.
- **parte3.php** — Construye una frase "cuñada" a partir de tres desplegables.
- **parte4.php** — Amplía la parte 3 con una frase aleatoria (`array_rand`) y campos para escribir opciones propias, que sustituyen al desplegable.
- **parte5.php** — Comparator: aplica `and`, `or`, `xor`, `+` o `-` entre dos valores mediante un `switch` y muestra el resultado y sus tipos.
- **parte6.php** — Convierte una frase en array con `explode` y la reconstruye con `implode`, quitando las posiciones pares (opción A) o cada "frío" (opción B).

La carpeta `img/` contiene las 6 caras del dado usadas en las partes 1 y 2.
